## Использование:

Откройте проект например в PyCharm, откройте файл main.py и запустите его.
По желанию можно его всячески модифицировать в рамках тестирования написанных функций.

Данное домашнее задание демонстрирует возможности bootstrap (часть возможностей),
и дает возможность познакомиться как взаимодействует написанный на python небольшой сервер
с html страницами.
